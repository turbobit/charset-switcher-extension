# i18n Contribution Guide

This project uses Chrome Extension i18n with `_locales/<locale>/messages.json`.

## Add a new language via PR

1. Create a new folder:
   - `_locales/<locale>/messages.json`
   - Example locale codes: `ja`, `fr`, `es`, `zh_CN`
2. Copy from `_locales/en/messages.json`.
3. Translate every `message` value.
4. Keep all message keys unchanged.
5. Run:
   - `npm run i18n:check`
6. Open PR with:
   - target locale code
   - screenshots (popup + settings)

## Notes

- Do not edit key names.
- Keep placeholders like `$1`, `$CHARSET$`, `$DOMAIN$` intact.
- If you add new keys, update all locale files in the same PR.
